# Spoken Function Calling Dataset

Version: **1228** (see `VERSION` at the repository root)

## Directory Layout

```text
data/
├── raw/final_data_1228/          # Raw JSONL (text query + function schema + labels)
├── audio/final_data_audio/       # Corresponding WAV audio files
├── processed/
│   ├── data_msswift/             # ms-swift training format (Function Call / SFC)
│   └── data_slu/                 # SLU format (Intent + Slots)
└── manifest.json                 # File manifest and sample statistics
```

## Splits

### Difficulty levels (raw JSONL)

| Level | Description |
|-------|-------------|
| `level_1` | Single function, relatively direct calls |
| `level_2` | Multiple candidate functions, moderate complexity |
| `level_3_1` | High-complexity scenario (variant 1) |
| `level_3_2` | High-complexity scenario (variant 2) |

### Dataset splits

| Split | Description |
|-------|-------------|
| `train_id` | Training set (in-domain APIs) |
| `test_id` | In-distribution test set |
| `test_ood` | Out-of-distribution test set (generalization) |

## Data Formats

### `processed/data_msswift/` (SFC)

- `messages`: user prompt (functions, environment, `<audio>` placeholder)
- `audios`: audio paths (relative: `audio/final_data_audio/...`)
- `solution`: function-call answer, e.g. `["add_reminder(content=\"...\", time=\"...\")"]`

### `processed/data_slu/` (SLU)

- `messages`: full user + assistant dialogue
- `audios`: audio paths
- assistant output: `[{"intent": "...", "slots": {...}}]`

### `raw/final_data_1228/` (raw)

Each JSONL line contains: `query`, `scenario`, `environment`, `available_function`, `Ground Truth`, `level`

## Path Normalization

Run `project/scripts/normalize_paths.sh` to convert audio paths in JSON files to repo-relative paths under `data/`.

Full statistics are in `manifest.json` (generated by `project/scripts/generate_manifest.sh`).
